# Pivot: AI Dev Workflow

## Old Direction (Abandoned)
AI Memory Bank - 知识库存档工具
- 问题：价值主张弱，Kiro能力展示不足

## New Direction  
**AI Dev Workflow** - 从 AI 对话自动生成开发工作流

### Core Value
导入一段Claude开发对话 → Kiro启动3个Agent并行分析 → 30秒后生成：
- Code Review报告
- 架构决策记录  
- GitHub Issues

### Why This Wins
1. 真实痛点：团队需要从对话提取行动项
2. 充分展示Kiro：多Agent并行编排
3. 技术深度：Structured Output、工作流、API集成
4. Wow Moment：30秒自动生成完整工作流

### Demo (2分钟)
1. 导入对话
2. 点击"Generate Workflow" 
3. 看3个Agent并行运行（Kiro HUD）
4. 查看结果：Code Review + Decision Log + 4 GitHub Issues
5. 一键导出到GitHub

- 今天：3个Agent + workflow编排
- 明天：UI + GitHub集成
- 后天：完整demo录制
